# CampusOS — College ERP

A production-grade, multi-tenant college ERP platform built with TanStack Start, Supabase, and React.

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- **Framework**: TanStack Start (full-stack React, SSR)
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth with RBAC
- **Styling**: Tailwind CSS v4
- **Router**: TanStack Router (file-based)
- **State**: TanStack Query

## Modules

- Academic Suite (Students, Academics, Attendance, Exams, LMS)
- Enterprise Suite (Finance, HRMS)
- Campus Operations (Library, Hostel, Transport, Inventory, Maintenance, Visitors, Security, Medical)
- Platform (Auth, Multi-Tenant, RBAC, Workflows, Notifications, Audit, Search, Documents, Plugin SDK)
